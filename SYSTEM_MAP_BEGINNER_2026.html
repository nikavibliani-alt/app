Merging code to GitHub does not automatically change what guests see. Only changing the LIVE web pages does.

If we merge today — what do guests see?

Short answer: nothing changes for guests unless we also replace the live web pages or change the URL.

Merge PRs to main onlyLive files untouched. Guests keep same page, same links, same behavior.NO CHANGE
Deploy pipeline functions onlyLive pages don't call them yet. Guests unchanged.NO CHANGE
Deploy + wire live admin to pipelineYou get swap/unlock on production admin. Guests still old guest page unless that file changes too.ADMIN ONLY
Replace checkin-guest-v2 with sandbox designEvery guest who opens the link sees the new UI on next refresh. Existing ?g= links should still work if cutover is done carefully.GUESTS CHANGE
Recommended cutover order:
1) Merge + deploy backend callables
2) Wire live admin → test moves/swaps yourself
3) Replace guest page when ready → one announcement to team
4) Retire old HK apps gradually
